# RaspoznanieTeksta

Курсовая работа. Распознавание рукописных букв, цифр и математических формул,
нарисованных мышкой на холсте. Два движка машинного обучения объединены в
**ансамбль** (итог = произведение их оценок кандидатов — по тестам это надёжнее
каждого движка отдельно):

| Движок | Подход |
|---|---|
| 🧠 Нейросеть | Deeplearning4j, MLP 400→128→64→softmax по классам, аугментация (сдвиги/повороты/масштаб) |
| 📊 Маш. обучение | kNN: 3 ближайших соседа голосуют с весом 1/(1+d) + «якорные» голоса центроидов классов |

## Возможности

- **Компактный UI**: функции распознавания — на панели слева, инструменты и
  настройки — на тулбаре сверху, холст по центру, результат внизу
  (в деталях видно, что ответил каждый движок)
- Режимы: Цифры / Буквы / Цифры+Буквы / **Формулы** (строчные латинские — sin, cos, x, y…)
- **2D-формулы «как в Word»**: дробь (числитель над чертой, знаменатель под),
  степень (маленькая цифра над буквой), индекс (под буквой), **радикал √ с чертой** —
  структура разбирается автоматически, «∑ В Word» вставляет нативные уравнения:
  `<mfrac>`, `<msup>`, `<msub>`, `<msqrt>`
- **Расширенный словарь знаков**: `+ - * / = ( ) ^ . , < > | √ π ≤ ≥ ≠` —
  по 24 варианта из 10 шрифтов на каждый класс (всего 2712 образцов, 113 классов)
- **⚡ Динамическое распознавание**: формула распознаётся на лету, после паузы
  700 мс в рисовании (включено по умолчанию)
- **🔍 Распознать / ≡ Строку**: ансамбль + окно кандидатов с уверенностью
- **📷 Фото**: формула с холста копируется в буфер картинкой (Ctrl+V в документ)
- **∑ В Word**: распознанная формула конвертируется в **MathML** — в Word
  (Вставка → Уравнение → Ctrl+V) она становится нативным уравнением:
  степени, дроби, функции (поддержка `^`, `/`, скобок, sin/cos/tg/log/ln)
- Обучение: «🎓 Обучить» добавляет образец в `data/samples_user.dat` сразу
- База: синтетическая `data/samples.dat` (SampleGenerator) + ваши образцы
  (`data/samples_user.dat`); резервная копия прежней базы — `data/samples_backup_old.dat`

## Запуск

### IntelliJ IDEA
1. `File → Open...` → выбрать `pom.xml` → **Open as Project**
2. Дождаться загрузки зависимостей Maven (при первом запуске скачается ~200 МБ)
3. Запустить `src/main/java/raspoznanieteksta/Main`

### Командная строка
```bash
mvn compile exec:java
```
Требуется JDK 17+ и Maven (или bundled Maven из IntelliJ IDEA).

## Как проходит эксперимент

1. **Обучение**: образец добавляется в «мой» файл; kNN работает сразу,
   нейросеть переобучается в фоне (статус внизу).
2. **Распознавание**: символ/строка нормализуется (обрезка, масштаб 20×20,
   сглаживание 3×3, центрирование по центру масс — `FeatureOps`), подаётся в оба
   движка, ответы объединяются ансамблем.
3. **Сравнение**: внизу показаны ответы обоих движков с уверенностью
   (доля кандидата среди топ-5, единая шкала) и итог ансамбля.

## Синтетическая база (SampleGenerator)

`data/samples.dat` пересоздаётся автоматически (1284 образца: цифры, RU А-ЯЁ,
EN A-Z/a-z, мат. символы — по 12 вариантов из 10 шрифтов, в т.ч. рукописных):

```bash
mvn compile exec:java -Dexec.mainClass=raspoznanieteksta.SampleGenerator
```

Файл перезаписывается — заранее сохраните копию. Поверх синтетической базы можно
добавлять свои рукописные образцы кнопкой «🎓 Обучить».
