# RaspoznanieTeksta

Курсовая работа. Распознавание рукописных букв, цифр и математических формул,
нарисованных мышкой на холсте. Два движка машинного обучения объединены в
**ансамбль** (итог = произведение их оценок кандидатов — по тестам это надёжнее
каждого движка отдельно):

| Движок | Подход |
|---|---|
| Нейросеть | Deeplearning4j, MLP 400→256→128→softmax(113), аугментация (сдвиги/повороты/масштаб) |
| Маш. обучение | kNN: 3 ближайших соседа голосуют с весом 1/(1+d) + «якорные» голоса центроидов классов |

Организация распознавания повторяет схему Microsoft **Ink to Math**: штрихи как
объекты → классификация символов → двумерный структурный разбор → уравнение
(у нас MathML, который редактор уравнений Word превращает в нативное уравнение).

## Возможности

- **Компактный UI**: функции распознавания — на панели слева, инструменты и
  настройки — на тулбаре сверху, холст по центру, результат внизу
  (в строке деталей видно, что ответил каждый движок)
- Режимы: Цифры / Буквы / Цифры+Буквы / **Формулы** (строчные латинские —
  sin, cos, x, y…)
- **2D-формулы «как в Word»**: дробь (числитель над чертой, знаменатель под),
  степень (маленькая цифра над буквой), индекс (под буквой), **радикал √ с
  чертой** — структура разбирается автоматически, «∑ В Word» вставляет
  нативные уравнения: `<mfrac>`, `<msup>`, `<msub>`, `<msqrt>`
- **Словарь знаков**: `+ - * / = ( ) ^ . , < > | √ π ≤ ≥ ≠` — по 24 варианта
  из 10 шрифтов на каждый класс (всего 2712 образцов, 113 классов)
- **Динамическое распознавание**: формула распознаётся на лету, после паузы
  700 мс в рисовании (включено по умолчанию)
- **Распознать символ / строку**: ансамбль + окно кандидатов с уверенностью
- **Фото**: формула с холста копируется в буфер картинкой (Ctrl+V в документ)
- **В Word (MathML)**: распознанная формула конвертируется в MathML — в Word
  (Вставка → Уравнение → Ctrl+V) она становится нативным уравнением: степени,
  дроби, функции (поддержка `^`, `_`, `/`, скобок, sin/cos/tg/log/ln, `√`)
- **Обучение**: «Обучить» добавляет нарисованный символ в «мой» файл
  (`data/samples_user.dat`) с автосохранением — оба движка сразу учатся на нём
- **Ластик и выделение на модели штрихов** (как в Word): ластик удаляет штрих
  целиком, стёртое исчезает физически — «призраков» в распознавании не остаётся

## Запуск

### IntelliJ IDEA
1. `File → Open...` → выбрать `pom.xml` → **Open as Project**
2. Дождаться загрузки зависимостей Maven (при первом запуске скачается ~200 МБ)
3. Запустить `src/main/java/raspoznanieteksta/Main`

### Командная строка
```bash
mvn compile exec:java
```
Требуется JDK 17+ и Maven (или bundled Maven из IntelliJ IDEA).

## Как работает распознавание

1. **Обучение**: образец добавляется в «мой» файл; kNN работает сразу,
   нейросеть переобучается в фоне (статус внизу).
2. **Распознавание**: рисунок нормализуется (обрезка, масштаб 20×20, сглаживание
   3×3, центрирование по центру масс — `FeatureOps`), подаётся в оба движка,
   ответы объединяются ансамблем.
3. **Формулы**: связные компоненты → 2D-структура (дробь/степень/индекс/
   радикал) → линейная строка → MathML.
4. **Сравнение**: внизу показаны ответы обоих движков с уверенностью (доля
   кандидата среди топ-5, единая шкала) и итог ансамбля.

Подробное описание модулей, алгоритмов и форматов данных — в
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Синтетическая база (SampleGenerator)

`data/samples.dat` пересоздаётся автоматически (2712 образцов: цифры, RU А-ЯЁ,
EN A-Z/a-z, знаки `+ - * / = ( ) ^ . , < > | √ π ≤ ≥ ≠` — по 24 варианта из
10 шрифтов, в т.ч. рукописных):

```bash
mvn compile exec:java -Dexec.mainClass=raspoznanieteksta.SampleGenerator
```

Файл перезаписывается — заранее сохраните копию. Поверх синтетической базы можно
добавлять свои рукописные образцы кнопкой «Обучить».

## Ограничения

- Символы, нарисованные вплотную (без пустых столбцов), распознаются как один
  фрагмент — лимит вертикальной проекции.
- Пары `o`/`0`, `|`/`l` и `9`/`q` неразличимы по форме (особенно у рукописных
  шрифтов) — выбор в окне кандидатов.
- Заглавные и строчные буквы у шрифтов совпадают по форме (x/X, s/S) — в режиме
  «Формулы» используются только строчные.
